# 首页设计稿

> 对应实现：`miniprogram/pages/home/index.*`。  
> 遵循 `design-system/校友社区/MASTER.md`，不改变现有「吸顶分类 + 搜索 + 推荐流」结构。

## 1. 页面目标

首页承担「发现社区正在发生什么」的职责。它不是资讯门户，也不是广告页，而是校友社区的主动态流：快速看见生活分享、专业问答、校友作者与可参与内容。

## 2. 信息区块

0. **背景装饰**
   - 团宠插画仅在**登录页**（`mascot-illust`），首页无背景猫装饰。

1. **吸顶分类栏**
   - 现有结构：`全部 / 生活 / 专业` 三个图形分类 + 右侧搜索入口。
   - 确认调整：右侧放大镜升级为完整搜索框入口，用于强化找人、找内容、找话题。
   - 优先级：一级导航内的内容筛选，必须稳定、轻量、可快速切换。
   - 设计要求：分类栏背景使用 `--color-bg` 或 `--color-surface-elevated`，底部只保留弱分割线 `--color-divider`。

2. **首屏加载 / 错误 / 空状态**
   - 现有结构：`feed-skeleton`、`state-block`。
   - 优先级：空状态必须给出动作「去发布」；错误状态给出「重试」。
   - 设计要求：状态图形使用浅墨绿圆形或简化公告牌形态，避免蓝灰渐变球。

3. **推荐内容流**
   - 现有结构：`content-card` 列表，`showAuthor=false`，作者行在标题下。
   - 优先级：标题 > 作者/时间 > 摘要/图片 > 互动数据。
   - 设计要求：卡片之间用 `20rpx` 间距，卡片自身以白底 + 细描边为主，不堆大阴影。

4. **加载更多反馈**
   - 现有结构：`加载失败，点此重试`、`没有更多了`。
   - 设计要求：重试文案使用 `--color-brand`；结束文案用 `--color-text-tertiary`。

## 3. 布局与栅格

- 移动端主栅格：页面水平边距 `24rpx`，卡片满宽。
- 分类栏：高度控制在 `112-128rpx`；三分类保持可读，搜索入口升级为宽 `188-220rpx` 的横向搜索框。
- 搜索框与分类的布局：分类区 `flex: 1`，搜索框 `flex-shrink: 0`；若 375px 机型空间不足，分类图标可保留但 label 间距压缩，不隐藏文字。
- 推荐流：`home__feed` 顶部 `8rpx`，卡片纵向间隔 `20rpx`。
- 底部：保留 `calc(120rpx + env(safe-area-inset-bottom))`，避免被自定义 tabBar 遮挡。

## 4. 组件规格

### 分类 Tab

- 默认：图标与文字 `--color-text-secondary`，字号 `26rpx`，字重 500。
- 激活：图标与文字 `--color-brand`，文字字重 600。
- 下划线：`48rpx × 6rpx`，圆角 `3rpx`，颜色 `--color-brand`。
- 触摸：`hover-class` 降透明度到 `0.85`，不缩放。
- 图标：沿用 CSS 几何自绘，线条色 `currentColor`，禁止 emoji。

### 搜索框入口（已确认纳入）

- 容器：宽 `188-220rpx`，高 `64rpx`，圆角 `999rpx`。
- 背景：`#FFFFFF` 或 `rgba(255,255,255,0.86)`；边框 `1rpx solid var(--color-border)`。
- 左侧图标：`28rpx` 视觉尺寸，描边 `3rpx`，颜色 `--color-text-tertiary`。
- 占位文案：`搜校友 / 内容` 或 `搜索校友与内容`，字号 `24rpx`，颜色 `--color-text-tertiary`，单行省略。
- 触摸区域：整个搜索框可点，点击仍进入现有 `ROUTES.SEARCH`，不在首页直接展开输入。
- 触摸反馈：背景加深为 `var(--color-brand-light)` 或 opacity `0.9`，不缩放。
- 极窄设备策略：文案可缩短为 `搜索`，搜索框宽度不低于 `168rpx`。

### 内容卡

- 背景：`--color-card-bg`。
- 圆角：`--radius-card`。
- Padding：`24rpx`。
- 边框：建议新增 `1rpx solid --color-border`。
- hover：`opacity: 0.96` 保持现状即可。
- 标题：`32rpx`，600，行高 1.35，最多 2 行。
- 摘要：`28rpx`，`--color-text-secondary`，行高 1.45，最多 3 行。
- 图片：单图高度 `240rpx`；多图 `190rpx × 150rpx`；占位底色从 `#f0f2f5` 改为 `#F0EDE7`。

### 骨架屏

- 骨架底色：`#E8E3DA`。
- 高光：`#F7F5F0`。
- 动画：`1.1s` 保持，但建议支持 `prefers-reduced-motion` 时禁用。

## 5. 色彩与语义

- 页面背景：`--color-bg`（暖灰纸色）。
- 分类激活、重试、专业内容强调：`--color-brand`。
- 搜索框背景：白底 + 弱描边；搜索图标和占位使用 `--color-text-tertiary`。
- 生活标签：`#F0EBE3 / #6B5B4F`。
- 专业标签：`--color-brand-light / --color-brand`。
- 分割线：`--color-divider`，替换现有 `rgba(0,0,0,0.04)`。

## 6. 字体与图标

- 页面不需要额外大标题，靠分类栏建立首屏节奏。
- 内容标题保持 `32rpx / 600`。
- 作者、时间、统计统一 `24rpx`，使用 `--color-text-tertiary`。
- 图标风格：线性几何，线宽 `3rpx`，圆角端点；不要新增照片感或拟物图标。

## 7. 关键交互

- 下拉刷新：保留，仅在信息流页合理。
- 快速切换分类：保留请求 token 保护；切换时清空列表并回到顶部。
- 搜索框点击：整框跳转搜索页；不拦截键盘、不在首页内联输入，避免改变当前搜索流程。
- 空状态：默认空「去发布」进入 `ROUTES.PUBLISH`；分区空提示「切换分区或下拉刷新」保持。
- 卡片点击：按内容类型进入生活/专业详情，错误类型 toast。
- 作者点击：进入用户主页。

## 8. 与现有实现衔接

1. **把首页激活蓝替换为深墨绿**
   - 涉及：`.home__cat--active`、`.home__cat--active::after`、重试文案。
   - 收益：立即去除 AI/SaaS 电蓝感。

2. **吸顶栏从硬白/灰改成暖纸底 + 弱分割**
   - 涉及：`.home__header`。
   - 收益：分类栏更像社区布告栏，不突兀。

3. **内容卡增加极细描边，减少阴影依赖**
   - 涉及：全局 `.card` 或 `content-card`。
   - 收益：列表层级更稳，避免模板卡片墙。

4. **图片占位色改暖灰**
   - 涉及：`.cc__single-img`、`.cc__gallery-img`、`.cc__pro-thumb`。
   - 收益：加载中也符合品牌氛围。

5. **搜索入口升级为完整搜索框**
   - 涉及：`home__search-hit`、搜索图标结构、`onSearchTap` 复用。
   - 收益：强化找人/找内容的入口，不改变搜索页业务流程。

6. **状态图形去蓝灰渐变**
   - 涉及：`state-block`。
   - 收益：空/错状态与主视觉一致。

## 9. 不纳入默认设计稿的大改建议

- 不新增首页活动 Banner，不重排为「Hero + 社区统计」。
- 不改变三分区筛选逻辑。
- 搜索入口升级为完整搜索框已确认纳入本轮；默认不做首页内联搜索输入。
