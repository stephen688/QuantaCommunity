# 关注页设计稿

> 对应实现：`miniprogram/pages/follow/index.*`。  
> 遵循 `design-system/校友社区/MASTER.md`，保持现有「标题 + 内容类型 tabs + 关注流」结构。

## 1. 页面目标

关注页是「熟人动态」区域，核心是降低噪音、突出已关注校友的更新。它应比首页更亲近、更稳定，强调作者身份和时间，而不是强推荐感。

## 2. 信息区块

1. **页面标题**
   - 现有：`关注动态`。
   - 职责：告诉用户当前是关系流，不是推荐流。
   - 设计要求：标题使用 `40rpx / 600`，颜色 `--color-text-primary`；可在后续增加副标题，但默认不新增功能。

2. **内容类型 Tabs**
   - 现有组件：`content-type-tabs`。
   - 职责：筛选关注对象发布的全部/生活/专业内容。
   - 设计要求：激活态从主文本 + 绿下划线体现，避免蓝色。

3. **关注流状态**
   - 骨架：`feed-skeleton variant="follow"`。
   - 错误：`state-block` + 重试。
   - 空：根据 `emptyReason` 显示「去首页看看」或「查看全部」。
   - 设计要求：空状态必须保留动作按钮，符合 Pro-Max 空状态指引。

4. **关注内容卡列表**
   - 现有：`content-card`，`showAuthor=true`。
   - 职责：作者信息比首页更重要。
   - 设计要求：作者行放在卡片首部，头像/昵称/时间形成稳定阅读锚点。

## 3. 布局与栅格

- 页面水平边距：`24rpx`。
- 标题区：顶部 `20rpx`，下方 `8rpx`，保持现状可略增到 `24rpx / 12rpx`。
- Tabs：左右内边距从 `8rpx` 可调整为 `0`，与卡片左边齐线。
- 列表：卡片纵向间隔 `20rpx`。
- 底部：保留 `calc(120rpx + env(safe-area-inset-bottom))`。

## 4. 组件规格

### 页面标题

- 字号：`40rpx`。
- 字重：600。
- 行高：1.25。
- 颜色：`--color-text-primary`。
- 如果添加副标题，使用 `24rpx`、`--color-text-tertiary`，文案例如「看看你关注的校友最近在聊什么」。

### 内容类型 Tabs

- 容器：底部边线 `1rpx solid --color-divider`。
- 间距：tab 间距 `32rpx` 保持。
- 默认文字：`30rpx / 400 / --color-text-secondary`。
- 激活文字：`30rpx / 600 / --color-text-primary`。
- 激活下划线：`48rpx × 6rpx`，颜色 `--color-brand`。
- 触摸：opacity `0.85`，不位移。

### 内容卡

- 使用全局 `content-card` 规范。
- 与首页差异：`author-row` 必须可见，头像建议 `64-72rpx`，昵称 `28rpx / 500`。
- 作者行与标题间距：`12rpx`。
- 统计区域：顶部边线 `--color-divider`，不要使用蓝色。

### 空状态

- `noFollow`：
  - 标题：还没有关注动态。
  - 说明：去发现页看看推荐内容。
  - 主操作：去首页看看，按钮使用 Ghost 或 Secondary。
- `noContentInFilter`：
  - 标题：关注的人还没有生活/专业内容。
  - 主操作：查看全部。
  - 触发后切回全部并滚到顶部，现有逻辑保留。

## 5. 色彩与语义

- 页面背景：`--color-bg`。
- 标题：`--color-text-primary`。
- Tabs 激活下划线：`--color-brand`。
- 空状态按钮边框：`rgba(30,90,76,0.35)`。
- 加载失败重试：`--color-brand`。
- 结束文案：`--color-text-tertiary`。

## 6. 字体与图标

- 标题使用 `--font-display`。
- Tab 文字介于导航与正文之间：`30rpx`，激活加粗。
- 作者行使用头像 + 文字，不新增装饰图标。
- 类型标签继续使用生活/专业的弱色语义。

## 7. 关键交互

- 下拉刷新：保留，刷新失败用 toast。
- 切换 tabs：清空列表、回顶部、请求 token 防止旧响应覆盖，现有逻辑正确。
- 触底加载：仅当已有列表且未结束时触发。
- 分区空状态按钮：切回全部。
- 卡片作者点击：进入用户主页，保持。

## 8. 与现有实现衔接

1. **`content-type-tabs` 全量 token 化**
   - 替换 `#e8eaed`、`#2f6bff` 为 `--color-divider`、`--color-brand`。
   - 收益：关注页与首页分类视觉统一。

2. **标题区增加一点呼吸感**
   - `.follow__head` 可改为 `padding: 24rpx 24rpx 12rpx`。
   - 收益：页面开头更稳，不像临时标题。

3. **空状态按钮改成品牌绿描边**
   - 涉及 `state-block`。
   - 收益：CTA 明确但不过度抢眼。

4. **作者行保持最高可见性**
   - 不隐藏头像，不弱化昵称。
   - 收益：关注页的关系属性更强。

5. **加载更多错误文案保留文本链接形态**
   - 只换颜色，不改为大按钮。
   - 收益：避免列表末端视觉过重。

## 9. 不纳入默认设计稿的大改建议

- 不新增关注分组、好友圈、推荐关注模块。
- 不把关注页改成双栏或瀑布流。
- 若后续要强化「关注对象管理」，需另行确认。
