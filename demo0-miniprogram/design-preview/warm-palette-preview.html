Token Color Applied To Role

--color-bg-base#FFFAF2Page backgroundCream canvas
Implementation Strategy

Phase 1: Token Swap

Replace app.wxss CSS variables. Pages auto-adopt via var().

Phase 2: Gradient Depth

Add warm gradients to CTA, tab bar publish, progress bars.

Phase 3: Temperature Refinement

Per-component tuning: hot for CTAs, pale for backgrounds.

Phase 4: Atmosphere

Subtle warm blobs on key pages, toned down from login.

Key Design Principle

This is not "make everything orange." It's a temperature spectrum: deep burnt orange for primary actions, warm mid for selected states, mellow for hover, amber for badges, sun yellow for atmosphere, pale orange for surfaces. Each shade has a specific semantic role.
